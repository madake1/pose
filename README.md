# POSE LAB · 位姿投影工作台

本地纯静态工具，用于查看四臂位姿、调节相机与器械安装参数，并将投影与手术视频同步对照。**无需部署，无需启动服务。**

## 打开

双击项目根目录的 `index.html`，使用新版 Edge / Chrome 打开。所有依赖已内嵌，断网也可用；运行时不需要安装 Node.js。通过页面左侧选择本地 TXT 和视频，文件不会上传。大视频通过浏览器本地文件 URL 播放，不会完整读入 JavaScript 内存。

展示区分三块：左侧为占满高度的 3D 场景，右上为相机投影，右下为视频叠加；不再单独显示原始视频。在叠加区点击“隐藏投影”即可检查原画面。初始没有虚构的真实位姿；“加载演示”使用明确标记的合成数据。

## 使用顺序

1. 建议一次多选本批全部 6 个 TXT，默认选择“全部日志 · 按绝对时间自动衔接”，也可单独切换文件。解析在后台线程分块进行；按文件、时间跳跃超过 1 秒、时间倒退或序号重置拆成片段。
2. 选择视频，在左侧最上方“当前视频 · 时间参数”输入该视频的起始绝对时间（`HH:mm:ss.SSS`），不再预设固定起点；若恢复了上次保存的参数，需确认起点属于当前视频。持续时间自动从当前视频读取，并显示结束绝对时间，不需要手动填写。时间属于同一录制日的时分秒，不依赖电脑日期 / 时区；目前不处理跨午夜。
3. 同步关系为 `日志绝对时间 = 视频起始绝对时间 + 时间微调 + 视频已播放秒数 × 时钟比例`。如视频或日志时钟仍有固定偏差，可调“时间微调”；若其他视频起点不同，可修改“视频起始绝对时间”。保留“用当前画面对齐”作为高级手动方法，重新独立选点前可清空起始时间。
4. 底部时间轴覆盖整段视频，可直接输入绝对时间跳转。播放时自动寻找已载入日志并跨文件衔接；自动切换只更换日志源，不改动已调好的相机 / 模型参数，也不会暂停视频。显式切换文件或手动选择片段时，会按相应日志推荐初始化摆位，并定位到与视频的交集；没有交集会提示。
5. 根据需要调整相机安装偏移、安装旋转、视场角 / 像素焦距、主点，或各器械的模型尺寸与安装修正。夹爪开合自动取日志角度计算，无需手调比例。暂停时调参也实时生效。
6. 使用多处相隔较远的时间点检验同一组参数。每个视频可通过“导出参数”单独保存 JSON，下次先选择视频，再“导入参数”恢复；本地文件需重新选择。在页面内更换视频会清空上一段视频的起始时间、时间微调和时钟比例，几何参数继续保留；新视频的持续时间会重新自动读取。

### 视频起点不等于日志采样点

本批视频起点 18:30:37.317 位于第二个 TXT 的 18:30:37.308 与 18:30:37.337 两条记录之间，相隔 29ms；按 `9/29` 比例插值，不需要人为拼出一条同时间戳的日志。位置线性插值，旋转四元数插值，夹持角同步插值。

视频共 3991 秒，覆盖 **18:30:37.317–19:37:08.317**。例如日志 18:39:11.087 对应视频 **513.770 秒（08:33.770）**。首个 TXT 的中午时段不与视频重合，不会硬对齐到视频零秒；最后日志超出视频终点的部分也不会压缩进视频。

不同文件的正常短采样间隔（≤150ms，序号未重置）允许跨文件插值；32767 与类型变化仍不插值。更大的缺口不外推、不延用旧姿态，3D 隐藏相关模型，投影提示缺日志，视频和绝对时间轴继续推进。例如 18:57:52.601–18:57:52.806 的 205ms 缺口会显示缺失，直到恢复日志。

视频定位最终受编码帧时刻限制，本批为 60fps；界面按实际显示帧的时间匹配日志，不能凭毫秒输入创造视频中不存在的帧。

## 推荐摆位与恢复

每个日志片段最多均匀抽取 1,000 帧，忽略 32767 与无效位姿，分别按行 / 列解释旋转矩阵，将器械位置转换到 arm2 局部坐标。比较哪个约定需要更小的相机 +Z 视轴修正，选择几何上更合理的初始约定。相机的推荐朝向由有效器械的平均单位视线决定（使用最小旋转保留原始滚转约定），视场角按 95% 样本所需范围加余量计算，限定在 45–130°，观察中心和距离由器械位置分布给出。侧栏显示所用样本数及推荐角度。

这只是方便观察的几何初始化，不是图像拟合或真实相机标定：光心平移、光学滚转、器械安装偏移、基座外参、时间关系无法仅凭这些日志唯一求出。它们不做伪拟合，平移 / 安装修正仍从零开始。器械朝向始终来自日志每帧旋转矩阵，推荐参数不把所有器械硬转向相机。无同时有效样本时明确提示无法拟合并使用原始朝向。

- 左侧“恢复推荐摆位”：恢复当前片段的相机参数、坐标约定、基座 / 器械安装修正与观察视角，保留模型尺寸、显隐、显示样式和时间对齐。
- 顶部“恢复推荐参数”：同时恢复模型尺寸和显示样式；仍保留时间对齐、当前时刻和已选文件。
- 3D 区“恢复视角”：仅恢复当前片段推荐的观察视角。

推荐参数独立于用户调参保存，重复恢复得到相同结果。不同片段的推荐相机修正可能不同，不能当成同一台相机的一套物理标定结果。

空格播放 / 暂停，左右方向键按 1/60 秒定位（本批视频为 60 fps；并非通用的编码帧级解码器）。无视频时可独立回放当前日志片段。有视频时以视频帧时间驱动位姿，暂停和缓冲不会让模型自行前进。

## 参数约定与当前边界

arm2 是动态相机：每个渲染时刻都会读取它当前的平移和旋转。相机公共位姿为 `基座外参 × arm2 日志位姿(t) × 固定光学安装修正`，随后转换到 Three.js 相机轴约定。相机模型、视锥、二维投影、视频叠加共用这一动态位姿。推荐安装参数只是固定修正，不会将相机锁在初始位置。相机参数区显示当前坐标，以及相对片段首个有效位姿的位移和转角。此转角是旋转矩阵间的最小夹角，不是欧拉角各分量相减。

- **观察相机与投影相机独立**：3D 观察角度 / 距离仅影响左侧视图。arm2 安装参数影响场景中的光学相机、投影和叠加。
- 日志前 9 数组成旋转矩阵、后 3 数是位置；加载后推荐行 / 列约定，变换方向初始为末端到基座，位置单位按毫米。推荐并非设备方确认。高级选项可改为按行 / 列、取逆、修改位置单位。四臂暂按共享基坐标系；若设备的四个基坐标不同，可在“各臂基座外参”分别设置到公共基座的固定变换（左乘），不能仅凭当前文件确认其数值。
- 固定安装修正右乘日志位姿，偏移在对应末端局部坐标下表达，旋转用 Three.js XYZ 欧拉角约定、界面单位为度。光学坐标为 X 右、Y 下、Z 前。默认 arm2 末端原点即光心、方向即光学方向，需要依据实际设备调试。
- 夹子原点为铰链，杆沿 −Z，夹爪沿 +Z。`lInsGrip` 按总开口角（弧度）解释：`θ = clamp(lInsGrip, 0, π)`，两片夹爪绕铰链分别旋转 `−θ/2` 与 `+θ/2`；理想尖端开距为 `2 × 夹爪长度 × sin(θ/2)`。负角按闭合显示并保留原始读数，不取绝对值；不再施加人为的比例 / 零点修正。日志单位与总角 / 单爪角约定仍需设备资料最终确认，简化模型不代表真实器械几何。
- 类型 32767、全零位姿或旋转矩阵明显无效会隐藏该臂。跨类型变化、无效位姿和超过 150ms 的采样间隔不插值；有效小间隔位置线性插值、旋转四元数插值。
- 近似针孔相机可调视场角，或使用视频原始分辨率下的 fx / fy。主点用图像宽高百分比表示。畸变使用 k1 / k2 / k3 与 p1 / p2，对投影图像施加 Brown–Conrady 畸变；3D 视锥显示未畸变的针孔范围。极端畸变可能无法稳定反解，画面外信息也不会被恢复。
- 叠加使用同一个原始视频帧和投影，不加入独立二维拖动修正；保留真实几何关系。只有设置时间映射且相机有效时才叠加。主点和视场角可改变投影落点 / 大小。
- 浏览器必须支持 WebGL、File.stream 与本地视频编码。当前 MP4 是否可播放取决于视频编码和浏览器；不兼容时页面会提示转为 H.264 MP4。此工具不负责视频转码。
- 支持多选 TXT 合并读取并按绝对时间查找本批日志；本批文件名的时间顺序与记录顺序一致。全部 6 个 TXT 共 271,696 行，数值数组约 137MiB，选择单文件可减少内存。视频播放不因日志缺口停止；日志独立回放仍按所选片段播放。
- 导入的参数仅是用户配置，不代表已经完成相机标定，也不证明投影与视频精确配准。

## 开发

源码位于 `src/`，使用 Three.js，解析器通过 Blob Worker 在 `file://` 下运行。构建产物是根目录单文件 `index.html`，无需 CDN 或服务。

```powershell
npm install
npm test
npm run build
```

`tests/real-data.test.mjs` 在存在原始数据时验证首个真实日志的解析、记录数量与时段重置；其他测试验证坐标变换、投影主点、无效器械和插值边界。`data/` 保持 Git 忽略，不打包进网页。

`node scripts/analyze-recommendations.mjs` 可在本机重算并打印全部 TXT 的推荐参数，用于检查初始化结果，不会上传或修改原始数据。

`node scripts/analyze-camera-motion.mjs` 扫描全部 arm2 日志并生成 `camera-motion-report.json`。比较连续有效记录中的约 1 秒窗口，排除 32767、时间断点和序号重置；另列相邻样本突变与较平滑的运动例子。统计仅说明日志位姿有变化，不能将所有突变直接认定为真实物理运动；位置暂按毫米解释。
